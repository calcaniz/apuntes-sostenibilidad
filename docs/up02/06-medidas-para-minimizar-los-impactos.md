# 6. Medidas para minimizar los impactos

Una vez identificado un impacto ambiental o social, el siguiente paso consiste en decidir cómo actuar. No todas las medidas son igual de eficaces: siempre es preferible evitar un impacto antes que intentar reparar posteriormente sus consecuencias.

## 6.1. Jerarquía de actuación

Las medidas pueden organizarse de acuerdo con el momento y la finalidad de la intervención.

| Tipo de medida { .table-bg-principal .table-cl-secundario .table-text-bold .table-main-column .table-full-container } | Finalidad { .table-bg-principal .table-cl-secundario .table-text-bold } | Ejemplo { .table-bg-principal .table-cl-secundario .table-text-bold } |
|---|---|---|
| **Prevención** | Evitar que el impacto llegue a producirse. | Diseñar un dispositivo que pueda repararse. |
| **Reducción** | Disminuir la intensidad o duración del impacto. | Reducir el consumo energético de una aplicación. |
| **Reparación** | Recuperar el entorno o la situación dañada. | Restaurar un espacio contaminado. |
| **Compensación** | Equilibrar un impacto que no se ha podido evitar. | Financiar una actuación ambiental equivalente. |

La compensación debe utilizarse como última opción. Compensar un daño no equivale a evitarlo.

!!! bloque-descriptivo "Idea clave"
    La mejor medida es la que actúa sobre la causa del problema y evita que el impacto llegue a producirse.

## 6.2. Mitigación y adaptación

Frente a algunos retos, especialmente el cambio climático, se diferencian dos grandes tipos de actuación:

- **Mitigación:** busca reducir las causas del problema.
- **Adaptación:** busca reducir sus consecuencias y prepararse para ellas.

| Estrategia { .table-bg-principal .table-cl-secundario .table-text-bold .table-main-column .table-full-container } | Pregunta principal { .table-bg-principal .table-cl-secundario .table-text-bold } | Ejemplo { .table-bg-principal .table-cl-secundario .table-text-bold } |
|---|---|---|
| **Mitigación** | ¿Cómo podemos reducir la causa? | Utilizar energía renovable y consumir menos electricidad. |
| **Adaptación** | ¿Cómo podemos prepararnos para sus efectos? | Preparar las infraestructuras para soportar temperaturas extremas. |

Ambas estrategias son necesarias. Aunque se reduzcan las causas, algunos efectos ya se están produciendo y requieren medidas de adaptación.

## 6.3. Niveles de actuación

Los grandes retos ambientales y sociales no pueden resolverse únicamente mediante decisiones individuales.

| Nivel { .table-bg-principal .table-cl-secundario .table-text-bold .table-main-column .table-full-container } | Posibles actuaciones { .table-bg-principal .table-cl-secundario .table-text-bold } |
|---|---|
| **Personal** | Consumir responsablemente, reparar dispositivos y reducir residuos. |
| **Empresarial** | Mejorar procesos, proteger a los trabajadores y seleccionar proveedores responsables. |
| **Público** | Aprobar normas, ofrecer servicios, controlar su cumplimiento e impulsar incentivos. |
| **Internacional** | Establecer acuerdos comunes para problemas que superan las fronteras. |

Las acciones personales son importantes, pero deben acompañarse de cambios empresariales, políticas públicas y cooperación internacional.

## 6.4. Medidas aplicadas al sector digital

En el sector digital pueden adoptarse medidas como:

| Reto { .table-bg-principal .table-cl-secundario .table-text-bold .table-main-column .table-full-container } | Medida { .table-bg-principal .table-cl-secundario .table-text-bold } |
|---|---|
| Consumo energético | Optimizar las aplicaciones y utilizar infraestructuras eficientes. |
| Residuos electrónicos | Reparar, reutilizar y alargar la vida útil de los dispositivos. |
| Brecha digital | Facilitar dispositivos, conexión y formación digital. |
| Falta de accesibilidad | Diseñar servicios utilizables por todas las personas. |
| Pérdida de privacidad | Recopilar únicamente los datos necesarios y protegerlos. |
| Condiciones laborales inadecuadas | Exigir criterios responsables a proveedores y subcontratas. |

Una medida puede generar nuevos impactos. Por ejemplo, sustituir todos los equipos por modelos más eficientes puede reducir el consumo eléctrico, pero también generar una gran cantidad de residuos.

Por ello, antes de actuar debemos analizar las consecuencias de la medida sobre toda la cadena de valor.

## 6.5. Cómo valorar una medida

Una medida adecuada debe:

- Actuar sobre una causa relevante.
- Ser concreta y viable.
- Identificar quién debe realizarla.
- Establecer un plazo.
- Permitir comprobar sus resultados.
- Evitar trasladar el impacto a otras personas o territorios.
- No generar un problema mayor que el que pretende resolver.

    ¿Sería sostenible cambiar todos los ordenadores de una empresa por modelos más eficientes si los anteriores todavía funcionan correctamente?
