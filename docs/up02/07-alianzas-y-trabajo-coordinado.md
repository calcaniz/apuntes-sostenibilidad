# 7. Alianzas y trabajo coordinado

Los retos ambientales y sociales son complejos y afectan a numerosos territorios, sectores y grupos de interés. Por esta razón, no pueden resolverse mediante la actuación aislada de una persona, empresa o administración.

Una **alianza** es un acuerdo de colaboración entre diferentes actores que comparten recursos, conocimientos y responsabilidades para alcanzar un objetivo común.

!!! bloque-descriptivo "Idea clave"
    Los grandes retos de sostenibilidad necesitan respuestas colectivas porque sus causas y consecuencias superan los límites de una organización o territorio.

## 7.1. ¿Por qué son necesarias las alianzas?

Las alianzas permiten:

- Compartir conocimientos y experiencias.
- Coordinar actuaciones.
- Evitar la duplicación de esfuerzos.
- Repartir responsabilidades.
- Disponer de más recursos.
- Establecer objetivos comunes.
- Afrontar problemas que superan las fronteras.
- Conseguir soluciones más duraderas.

Por ejemplo, una empresa puede diseñar dispositivos reparables, pero necesitará proveedores que suministren piezas, administraciones que regulen su gestión y consumidores que los utilicen responsablemente.

## 7.2. Actores implicados

| Actor { .table-bg-principal .table-cl-secundario .table-text-bold .table-main-column .table-full-container } | Función principal { .table-bg-principal .table-cl-secundario .table-text-bold } |
|---|---|
| **Administraciones públicas** | Aprobar normas, controlar su cumplimiento y ofrecer servicios públicos. |
| **Empresas** | Transformar productos, servicios, procesos y cadenas de suministro. |
| **Trabajadores** | Aplicar las medidas y aportar conocimiento sobre los procesos. |
| **Ciudadanía** | Consumir responsablemente y participar en las decisiones. |
| **Centros educativos y universidades** | Formar, investigar y difundir conocimientos. |
| **Organizaciones sociales** | Representar a colectivos y detectar necesidades sociales. |
| **Organizaciones ambientales** | Defender los ecosistemas y proponer medidas de protección. |
| **Organismos internacionales** | Coordinar acuerdos entre países. |

Ninguno de estos actores dispone por sí solo de toda la información, los recursos o la capacidad necesarios.

## 7.3. Trabajo transversal

Trabajar de manera **transversal** significa incorporar la sostenibilidad en diferentes áreas de una organización.

En una empresa tecnológica pueden participar:

| Área { .table-bg-principal .table-cl-secundario .table-text-bold .table-main-column .table-full-container } | Posible responsabilidad { .table-bg-principal .table-cl-secundario .table-text-bold } |
|---|---|
| **Dirección** | Establecer objetivos y asignar recursos. |
| **Desarrollo** | Crear aplicaciones eficientes, seguras y accesibles. |
| **Sistemas** | Gestionar infraestructuras, servidores y consumo energético. |
| **Compras** | Seleccionar equipos y proveedores responsables. |
| **Recursos humanos** | Garantizar igualdad, formación y condiciones laborales adecuadas. |
| **Comunicación** | Informar con transparencia sobre los resultados. |

Si solo actúa un departamento, pueden aparecer contradicciones. Por ejemplo, el área técnica puede optimizar una aplicación mientras compras adquiere dispositivos de corta duración.

## 7.4. Ejemplo: residuos electrónicos

La gestión de los residuos electrónicos necesita la participación coordinada de diferentes actores.

| Actor { .table-bg-principal .table-cl-secundario .table-text-bold .table-main-column .table-full-container } | Actuación { .table-bg-principal .table-cl-secundario .table-text-bold } |
|---|---|
| **Fabricantes** | Diseñar dispositivos duraderos y reparables. |
| **Empresas** | Mantener, reutilizar y entregar correctamente los equipos. |
| **Administraciones** | Regular la recogida y controlar su tratamiento. |
| **Consumidores** | Alargar la utilización y entregar los dispositivos en puntos autorizados. |
| **Gestores de residuos** | Recuperar materiales y tratar las sustancias peligrosas. |
| **Centros educativos** | Promover la utilización responsable de la tecnología. |

Si uno de estos actores no cumple su función, la solución pierde eficacia.

## 7.5. Condiciones de una alianza eficaz

Para que una alianza funcione debe disponer de:

- Un objetivo común.
- Responsabilidades claramente definidas.
- Recursos suficientes.
- Comunicación entre los participantes.
- Indicadores para comprobar los resultados.
- Transparencia.
- Continuidad en el tiempo.

Colaborar no significa que todos los participantes realicen la misma tarea, sino que sus acciones estén coordinadas.
