### 3.1. Selección de los ODS relevantes

Una organización puede estar relacionada con muchos ODS, pero no todos tienen la misma importancia para su actividad.

Seleccionar los ODS relevantes consiste en identificar aquellos sobre los que la organización:

- Produce un impacto ambiental o social.
- Puede influir mediante sus decisiones.
- Encuentra riesgos u oportunidades.
- Tiene capacidad para realizar acciones concretas.
- Responde a las necesidades de sus grupos de interés.

!!! bloque-descriptivo "Idea clave"
    Una empresa no debe seleccionar un ODS solamente porque su actividad pueda relacionarse de forma general con él. La relación debe justificarse mediante impactos, decisiones o acciones concretas.

### 3.2. Tipos de relación con los ODS

La relación entre una actividad profesional y un ODS puede ser directa, indirecta o condicionada.

| Tipo de relación { .table-full-container .table-content .table-bg-principal .table-cl-secundario } | Descripción { .table-bg-principal .table-cl-secundario } | Ejemplo { .table-bg-principal .table-cl-secundario } |
|---|---|---|
| **Directa** { .table-main-column .table-bg-principal .table-cl-secundario } | La actividad actúa directamente sobre el objetivo. | Una plataforma educativa accesible contribuye al acceso a la educación. |
| **Indirecta** { .table-main-column .table-bg-principal .table-cl-secundario } | La actividad influye en el objetivo mediante sus procesos o decisiones. | Optimizar una aplicación reduce la transferencia de datos y el consumo de recursos. |
| **Condicionada** { .table-main-column .table-bg-principal .table-cl-secundario } | La contribución depende de cómo se diseñe o utilice la tecnología. | La inteligencia artificial puede generar innovación, pero también discriminación o un consumo elevado de recursos. |

Una misma actividad puede contribuir positivamente a un ODS y, al mismo tiempo, perjudicar a otro.

### 3.3. Criterios para seleccionar un ODS

Para determinar si un ODS es relevante para una actividad profesional, pueden utilizarse las siguientes preguntas:

| Pregunta { .table-full-container .table-content .table-bg-principal .table-cl-secundario } | Finalidad { .table-bg-principal .table-cl-secundario } |
|---|---|
| **¿Qué impactos produce la actividad?** { .table-main-column .table-bg-principal .table-cl-secundario } | Relacionar la actividad con retos ambientales o sociales. |
| **¿A quién puede afectar?** { .table-main-column .table-bg-principal .table-cl-secundario } | Identificar las personas y grupos de interés implicados. |
| **¿Qué decisiones puede tomar la organización?** { .table-main-column .table-bg-principal .table-cl-secundario } | Comprobar si existe capacidad real de actuación. |
| **¿Qué resultados pueden medirse?** { .table-main-column .table-bg-principal .table-cl-secundario } | Evitar relaciones generales que no puedan demostrarse. |

### 3.5. Priorización de los ODS

Una organización no necesita trabajar simultáneamente todos los objetivos. Es preferible seleccionar un número reducido de ODS y desarrollar acciones reales.

Para priorizarlos se puede valorar:

1. La importancia del impacto.
2. La capacidad de actuación de la organización.
3. La relevancia para los grupos de interés.
4. La posibilidad de medir los resultados.

Por ejemplo, una empresa de desarrollo web podría priorizar:

- **ODS 8**, por las condiciones laborales de su plantilla.
- **ODS 10**, por la accesibilidad de sus aplicaciones.
- **ODS 12**, por el consumo de recursos y los dispositivos utilizados.
- **ODS 16**, por la privacidad, la seguridad y la transparencia.

!!! bloque-descriptivo "Reflexión"
    Una empresa afirma que contribuye al ODS 13 porque utiliza documentación digital en lugar de papel. Sin embargo, no mide el consumo de sus servidores ni optimiza sus aplicaciones. ¿Consideras suficientemente justificada su relación con este ODS?
