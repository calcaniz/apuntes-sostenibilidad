# 4. Riesgos y oportunidades

## 4.1. Los ODS como herramienta de análisis

Los ODS permiten identificar cambios ambientales, sociales, económicos y normativos que pueden afectar a una organización.

Estos cambios pueden representar:

- **Riesgos**, cuando pueden producir pérdidas, sanciones, interrupciones o daños.
- **Oportunidades**, cuando permiten innovar, reducir costes, mejorar servicios o acceder a nuevos mercados.

En la UP01 ya se estudiaron los riesgos y oportunidades **ASG**. Allí el punto de partida era la propia empresa: qué asuntos ambientales, sociales y de gobernanza la afectan. En esta unidad cambia la perspectiva: partimos de los **objetivos y metas globales** y nos preguntamos qué significan para la empresa. Los dos enfoques se complementan: los criterios ASG ayudan a detectar los asuntos, y los ODS ayudan a situarlos dentro de una agenda compartida por gobiernos, empresas y ciudadanía.

!!! bloque-descriptivo "Idea clave"
    Un ODS no constituye por sí mismo un riesgo o una oportunidad. Estos aparecen cuando sus retos y metas se relacionan con la actividad de una organización.

## 4.2. Principales tipos de riesgos

| Tipo de riesgo { .table-full-container .table-content .table-bg-principal .table-cl-secundario } | Descripción { .table-bg-principal .table-cl-secundario } | Ejemplo en el sector digital { .table-bg-principal .table-cl-secundario } |
|---|---|---|
| **Operativo** { .table-main-column .table-bg-principal .table-cl-secundario } | Puede dificultar el funcionamiento habitual de la organización. | Una interrupción del suministro energético afecta a los servidores. |
| **Económico** { .table-main-column .table-bg-principal .table-cl-secundario } | Puede aumentar los costes o reducir los ingresos. | El incremento del precio de la energía encarece el alojamiento web. |
| **Normativo** { .table-main-column .table-bg-principal .table-cl-secundario } | Procede de las obligaciones legales actuales o futuras que la organización debe cumplir. | Una aplicación incumple los requisitos de privacidad o accesibilidad. |
| **Reputacional** { .table-main-column .table-bg-principal .table-cl-secundario } | Puede perjudicar la confianza de clientes, plantilla o inversores. | Una filtración de datos se gestiona sin transparencia. |
| **Social** { .table-main-column .table-bg-principal .table-cl-secundario } | Puede afectar negativamente a las personas relacionadas con la organización. | La falta de desconexión digital provoca malestar y rotación laboral. |

Estos riesgos rara vez aparecen aislados. Un mismo problema puede generar varios a la vez: una brecha de seguridad es un riesgo **operativo** (el servicio deja de funcionar), **normativo** (puede suponer una sanción), **económico** (hay que pagar la sanción y la reparación) y **reputacional** (las personas usuarias dejan de confiar). Por eso, al analizar un riesgo conviene preguntarse qué otros riesgos puede desencadenar.

## 4.3. Cuando los ODS se convierten en obligaciones

Muchas metas de los ODS se trasladan a la legislación. Cuando esto ocurre, lo que era una recomendación pasa a ser una obligación, y no cumplirla se convierte en un riesgo normativo.

En el sector digital destacan las siguientes normas:

| Norma { .table-full-container .table-bg-principal .table-cl-secundario } | Qué exige { .table-bg-principal .table-cl-secundario } | ODS relacionado { .table-bg-principal .table-cl-secundario } |
|---|---|---|
| **Reglamento General de Protección de Datos (RGPD) y Ley Orgánica 3/2018 (LOPDGDD)** { .table-main-column .table-bg-principal .table-cl-secundario } | Tratar los datos personales con una base legítima, informar a las personas y proteger sus datos. La LOPDGDD reconoce además el derecho a la desconexión digital de las personas trabajadoras. | ODS 16 (16.10) y ODS 8 (8.8) |
| **Real Decreto 1112/2018** { .table-main-column .table-bg-principal .table-cl-secundario } | Que los sitios web y las aplicaciones móviles del sector público sean accesibles. | ODS 10 (10.2) |
| **Ley 11/2023 (Acta Europea de Accesibilidad)** { .table-main-column .table-bg-principal .table-cl-secundario } | Que determinados productos y servicios, como el comercio electrónico o la banca en línea, sean accesibles desde el 28 de junio de 2025, con algunos periodos de transición que llegan hasta 2030. | ODS 10 (10.2) |
| **Real Decreto 110/2015, sobre residuos de aparatos eléctricos y electrónicos (modificado por el Real Decreto 27/2021)** { .table-main-column .table-bg-principal .table-cl-secundario } | Entregar los equipos al final de su vida útil a gestores autorizados para su reutilización o reciclaje. | ODS 12 (12.5) |
| **Directiva (UE) 2022/2464 sobre información corporativa en materia de sostenibilidad (CSRD), modificada por la Directiva (UE) 2026/470 (Ómnibus I)** { .table-main-column .table-bg-principal .table-cl-secundario } | Que las empresas de mayor tamaño (más de 1.000 personas trabajadoras y más de 450 millones de euros de facturación) publiquen información sobre sus impactos, riesgos y oportunidades de sostenibilidad siguiendo las normas ESRS. | ODS 12 (12.6) |

El caso de la accesibilidad muestra bien esta evolución. Durante años fue una buena práctica recomendada; primero se exigió a las administraciones públicas y, desde 2025, también a muchas empresas privadas. Las organizaciones que se anticiparon no tuvieron que rehacer sus servicios con prisas: para ellas, la nueva obligación fue una oportunidad.

!!! bloque-descriptivo "Normativa en evolución"
    Estas normas cambian con frecuencia. Por ejemplo, la CSRD se aprobó en 2022 para unas 50.000 empresas europeas, y en 2026 la Unión Europea redujo su alcance a unas 10.000, las de mayor tamaño. También el RGPD está en revisión dentro del paquete europeo de simplificación digital (Ómnibus digital). Antes de utilizar una norma en un análisis, conviene comprobar su versión vigente en fuentes oficiales como el BOE o EUR-Lex.

## 4.4. Principales tipos de oportunidades

| Tipo de oportunidad { .table-full-container .table-content .table-bg-principal .table-cl-secundario } | Descripción { .table-bg-principal .table-cl-secundario } | Ejemplo en el sector digital { .table-bg-principal .table-cl-secundario } |
|---|---|---|
| **Eficiencia** { .table-main-column .table-bg-principal .table-cl-secundario } | Permite reducir el consumo de recursos y los costes. | Optimizar imágenes disminuye la transferencia de datos. |
| **Innovación** { .table-main-column .table-bg-principal .table-cl-secundario } | Favorece la creación de nuevos productos o servicios. | Desarrollar herramientas digitales para la educación a distancia. |
| **Acceso a mercados** { .table-main-column .table-bg-principal .table-cl-secundario } | Permite llegar a nuevos clientes o colectivos. | Una aplicación accesible puede utilizarse por más personas. |
| **Talento** { .table-main-column .table-bg-principal .table-cl-secundario } | Facilita la atracción y permanencia de profesionales. | Ofrecer formación, igualdad y medidas de conciliación. |
| **Financiación** { .table-main-column .table-bg-principal .table-cl-secundario } | Mejora el acceso a inversores o entidades financieras. | Comunicar indicadores ASG de forma transparente. |

Las oportunidades no aparecen solas: hay que buscarlas. La pregunta útil no es solo «¿qué puede salir mal?», sino también «¿qué necesidad no está bien resuelta?». Muchos productos digitales con éxito nacieron de atender a colectivos que los servicios existentes dejaban fuera, como personas mayores, personas con discapacidad o zonas con mala conexión.

## 4.5. Un mismo asunto puede ser riesgo y oportunidad

Una organización puede interpretar una misma situación de diferentes formas.

| Situación { .table-full-container .table-content .table-bg-principal .table-cl-secundario } | Riesgo { .table-bg-principal .table-cl-secundario } | Oportunidad { .table-bg-principal .table-cl-secundario } | ODS relacionado { .table-bg-principal .table-cl-secundario } |
|---|---|---|---|
| **Aumento del precio de la energía** { .table-main-column .table-bg-principal .table-cl-secundario } | Incremento del coste de la infraestructura. | Optimizar aplicaciones y utilizar servicios más eficientes. | ODS 7 y ODS 13 |
| **Nuevos requisitos de accesibilidad** { .table-main-column .table-bg-principal .table-cl-secundario } | Costes de adaptación o pérdida de clientes. | Mejorar el servicio y ampliar el número de personas usuarias. | ODS 10 |
| **Mayor preocupación por la privacidad** { .table-main-column .table-bg-principal .table-cl-secundario } | Sanciones y pérdida de confianza. | Diferenciarse mediante servicios seguros y transparentes. | ODS 16 |
| **Demanda de condiciones laborales responsables** { .table-main-column .table-bg-principal .table-cl-secundario } | Rotación, conflictos o dificultad para contratar. | Atraer talento y mejorar la productividad. | ODS 5 y ODS 8 |

Que una situación se convierta en riesgo o en oportunidad depende, sobre todo, del momento en que la organización reacciona. Quien actúa antes de que el cambio sea obligatorio o urgente suele encontrar oportunidades; quien espera, normalmente solo encuentra costes.

## 4.6. Valoración de los riesgos

No todos los riesgos tienen la misma prioridad. Para valorarlos se combinan dos factores:

- **Probabilidad:** ¿es fácil que ocurra?
- **Consecuencias:** si ocurre, ¿qué gravedad tienen sus efectos para la organización y para las personas?

Un riesgo con consecuencias graves y probabilidad elevada debe atenderse en primer lugar. Un riesgo poco probable y con consecuencias leves puede vigilarse sin necesidad de actuar de inmediato.

| Riesgo { .table-full-container .table-content .table-bg-principal .table-cl-secundario } | Probabilidad { .table-bg-principal .table-cl-secundario } | Consecuencias { .table-bg-principal .table-cl-secundario } | Prioridad { .table-bg-principal .table-cl-secundario } |
|---|---|---|---|
| **La aplicación no cumple los requisitos de accesibilidad exigidos** { .table-main-column .table-bg-principal .table-cl-secundario } | Alta | Graves: sanciones y exclusión de personas usuarias. | Alta |
| **Filtración de datos por una contraseña débil en un servidor** { .table-main-column .table-bg-principal .table-cl-secundario } | Media | Graves: sanción, daño reputacional y perjuicio para las personas afectadas. | Alta |
| **Subida puntual del precio del alojamiento** { .table-main-column .table-bg-principal .table-cl-secundario } | Media | Leves: aumento moderado de los costes. | Baja |

!!! bloque-descriptivo "Pregunta de reflexión"
    Una nueva normativa obliga a mejorar la accesibilidad de las aplicaciones web. ¿Representa únicamente un coste para la empresa o puede convertirse también en una oportunidad?
