# 5. Acciones profesionales y personales

## 5.1. De los objetivos a las acciones

Los ODS establecen objetivos generales, pero para contribuir a ellos es necesario convertirlos en actuaciones concretas.

Una acción sostenible debe responder a estas preguntas:

| Elemento { .table-full-container .table-content .table-bg-principal .table-cl-secundario } | Pregunta { .table-bg-principal .table-cl-secundario } |
|---|---|
| **Acción** { .table-main-column .table-bg-principal .table-cl-secundario } | ¿Qué se va a hacer? |
| **Responsable** { .table-main-column .table-bg-principal .table-cl-secundario } | ¿Quién debe realizarla? |
| **Plazo** { .table-main-column .table-bg-principal .table-cl-secundario } | ¿Cuándo debe estar completada? |
| **Indicador** { .table-main-column .table-bg-principal .table-cl-secundario } | ¿Cómo se comprobará el resultado? |
| **Objetivo** { .table-main-column .table-bg-principal .table-cl-secundario } | ¿Qué valor del indicador se quiere alcanzar? |
| **ODS y meta** { .table-main-column .table-bg-principal .table-cl-secundario } | ¿A qué objetivo y meta contribuye? |

Si falta alguno de estos elementos, la acción pierde fuerza. Sin responsable, nadie la realiza; sin plazo, se aplaza indefinidamente; sin indicador ni objetivo, nadie puede saber si ha funcionado.

!!! bloque-descriptivo "Idea clave"
    Una intención expresa lo que se desea conseguir. Una acción indica qué se hará, quién lo hará, en qué plazo y cómo se comprobará.

## 5.2. Acciones desde el ámbito profesional

Las personas que trabajan en el sector digital pueden contribuir a la sostenibilidad mediante las decisiones tomadas durante el diseño, el desarrollo y el mantenimiento de aplicaciones.

| Ámbito { .table-full-container .table-content .table-bg-principal .table-cl-secundario } | Acción profesional { .table-bg-principal .table-cl-secundario } | ODS relacionado { .table-bg-principal .table-cl-secundario } |
|---|---|---|
| **Eficiencia** { .table-main-column .table-bg-principal .table-cl-secundario } | Optimizar imágenes, vídeos, código y consultas para reducir el consumo de recursos. | ODS 7, 12 y 13 |
| **Accesibilidad** { .table-main-column .table-bg-principal .table-cl-secundario } | Diseñar y comprobar las aplicaciones utilizando criterios de accesibilidad. | ODS 4 y ODS 10 |
| **Privacidad** { .table-main-column .table-bg-principal .table-cl-secundario } | Recoger solamente los datos necesarios y protegerlos adecuadamente. | ODS 16 |
| **Equipos** { .table-main-column .table-bg-principal .table-cl-secundario } | Prolongar la vida útil de los dispositivos y gestionar correctamente su retirada. | ODS 12 |
| **Trabajo** { .table-main-column .table-bg-principal .table-cl-secundario } | Respetar la igualdad, la formación, la conciliación y la desconexión digital. | ODS 5 y ODS 8 |
| **Proveedores** { .table-main-column .table-bg-principal .table-cl-secundario } | Incorporar criterios ambientales y sociales en la contratación de servicios tecnológicos. | ODS 8, 12 y 17 |

Estas actuaciones pueden realizarse desde diferentes perfiles profesionales: desarrollo, diseño, sistemas, dirección, atención a personas usuarias o gestión de proyectos. No todas dependen de la dirección de la empresa. Muchas forman parte del trabajo diario de un desarrollador: elegir el formato de una imagen, evitar una librería innecesaria, etiquetar correctamente un formulario o no pedir un dato que no se va a utilizar.


## 5.3. Acciones desde el ámbito personal

Las decisiones personales también pueden contribuir a la sostenibilidad. Como profesionales del sector digital, además, conocemos mejor que la mayoría cómo funcionan los dispositivos y los servicios que usamos, y eso nos permite tomar decisiones más informadas.

| Ámbito { .table-full-container .table-bg-principal .table-cl-secundario } | Acción personal { .table-bg-principal .table-cl-secundario } | ODS relacionado { .table-bg-principal .table-cl-secundario } |
|---|---|---|
| **Dispositivos** { .table-main-column .table-bg-principal .table-cl-secundario } | Reparar, reutilizar o donar los dispositivos antes de sustituirlos, y valorar la compra de equipos reacondicionados. | ODS 12 (12.5) |
| **Consumo energético** { .table-main-column .table-bg-principal .table-cl-secundario } | Apagar los equipos cuando no se utilizan y ajustar su configuración energética. | ODS 7 y ODS 13 |
| **Uso de datos** { .table-main-column .table-bg-principal .table-cl-secundario } | Eliminar archivos innecesarios de la nube, desactivar la reproducción automática y no usar más calidad de vídeo de la necesaria. | ODS 12 y ODS 13 |
| **Bienestar digital** { .table-main-column .table-bg-principal .table-cl-secundario } | Gestionar las notificaciones y reservar tiempos sin pantallas. | ODS 3 |
| **Privacidad** { .table-main-column .table-bg-principal .table-cl-secundario } | Revisar los permisos de las aplicaciones y los datos que compartimos. | ODS 16 |
| **Formación** { .table-main-column .table-bg-principal .table-cl-secundario } | Actualizar los conocimientos y compartir recursos educativos. | ODS 4 |
| **Participación** { .table-main-column .table-bg-principal .table-cl-secundario } | Colaborar en proyectos de software libre o ayudar a personas con dificultades digitales. | ODS 10 y ODS 17 |
| **Convivencia digital** { .table-main-column .table-bg-principal .table-cl-secundario } | Utilizar las plataformas de forma segura, respetuosa y responsable. | ODS 16 |

Una buena acción personal tiene cuatro características:

- **Es concreta:** describe un hábito preciso, no una intención general.
- **Es realista:** se puede mantener en la vida diaria sin un esfuerzo excesivo.
- **Se mantiene en el tiempo:** un cambio puntual tiene poco efecto; un hábito sostenido, mucho más.
- **Se puede comprobar:** con herramientas sencillas, como el registro de uso del móvil, el espacio ocupado en la nube o los años de uso de un dispositivo.

## 5.4. De una intención a una acción medible

Una propuesta demasiado general resulta difícil de aplicar y evaluar.

| Intención { .table-full-container .table-content .table-bg-principal .table-cl-secundario } | Acción concreta { .table-bg-principal .table-cl-secundario } |
|---|---|
| **Reducir el consumo de la web.** { .table-main-column .table-bg-principal .table-cl-secundario } | Reducir en un 20 % el peso medio de las páginas durante los próximos tres meses mediante la optimización de imágenes. |
| **Mejorar la accesibilidad.** { .table-main-column .table-bg-principal .table-cl-secundario } | Revisar mediante pruebas automáticas y manuales todas las páginas principales antes de publicar la siguiente versión. |
| **Cuidar a la plantilla.** { .table-main-column .table-bg-principal .table-cl-secundario } | Implantar durante el próximo mes una política de desconexión digital y revisar su cumplimiento trimestralmente. |
| **Generar menos residuos.** { .table-main-column .table-bg-principal .table-cl-secundario } | Ampliar a cinco años la vida útil prevista de los equipos siempre que su estado permita utilizarlos con seguridad. |
| **Usar menos el móvil.** { .table-main-column .table-bg-principal .table-cl-secundario } | Desactivar esta semana las notificaciones no esenciales y comprobar con el registro de uso si el tiempo diario baja un 20 % en un mes. |

En todos los casos, la acción concreta responde a las preguntas del apartado 5.1: qué se hará, en qué plazo y cómo se comprobará.

## 5.5. Responsabilidad compartida

La contribución a los ODS requiere la participación de diferentes actores:

- Las **organizaciones** establecen políticas, recursos y objetivos.
- Los **equipos profesionales** aplican las acciones en los proyectos.
- Las **personas trabajadoras** incorporan buenas prácticas.
- Los **proveedores** deben cumplir los criterios acordados.
- Las **personas usuarias** pueden comunicar necesidades y problemas.

!!! bloque-descriptivo "Pregunta de reflexión"
    Una empresa pide a su plantilla que apague los ordenadores al terminar la jornada, pero mantiene aplicaciones poco eficientes y servidores sobredimensionados. ¿Está repartiendo correctamente la responsabilidad?
