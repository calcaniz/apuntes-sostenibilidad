# 6. Plan de actuación

## 6.1. Finalidad del plan

Un plan de actuación permite convertir los ODS seleccionados en decisiones organizadas, realistas y evaluables.

El plan reúne en un único documento todo lo trabajado en la unidad: parte de la situación inicial, selecciona los ODS y sus metas (apartado 3), analiza los riesgos y las oportunidades (apartado 4) y define acciones con la estructura vista en el apartado 5.

!!! bloque-descriptivo "Idea clave"
    Relacionar una actividad con un ODS solamente tiene valor si posteriormente se establecen acciones concretas y se comprueba su resultado.

## 6.2. Fases del plan

| Fase { .table-full-container .table-content .table-bg-principal .table-cl-secundario } | Pregunta principal { .table-bg-principal .table-cl-secundario } | Resultado { .table-bg-principal .table-cl-secundario } |
|---|---|---|
| **1. Diagnóstico** { .table-main-column .table-bg-principal .table-cl-secundario } | ¿Cuál es la situación actual? | Identificación del problema o necesidad, con datos iniciales. |
| **2. Selección** { .table-main-column .table-bg-principal .table-cl-secundario } | ¿Qué ODS y metas están relacionados? | ODS prioritario y justificación. |
| **3. Análisis** { .table-main-column .table-bg-principal .table-cl-secundario } | ¿Qué riesgo u oportunidad representa? | Consecuencias para la organización y las personas. |
| **4. Actuación** { .table-main-column .table-bg-principal .table-cl-secundario } | ¿Qué debe hacerse? | Acción con responsable, plazo y objetivo. |
| **5. Seguimiento** { .table-main-column .table-bg-principal .table-cl-secundario } | ¿Cómo se comprobará? | Indicador y revisión periódica de los resultados. |

Estas fases siguen el mismo orden que los pasos del SDG Compass presentados en la introducción: comprender la situación, priorizar, fijar objetivos, integrar las acciones y medir los resultados.


## 6.3. Priorización de las acciones

Una organización puede detectar muchas acciones posibles. Para decidir por cuáles empezar, se valoran con los mismos criterios utilizados para priorizar los ODS (apartado 3.6), agrupados en dos factores:

- **Importancia:** gravedad del impacto, relevancia para los grupos de interés y relación con la actividad.
- **Viabilidad:** capacidad de actuación, coste, plazo y posibilidad de medir el resultado.

| Importancia { .table-full-container .table-content .table-bg-principal .table-cl-secundario } | Viabilidad alta { .table-bg-principal .table-cl-secundario } | Viabilidad media { .table-bg-principal .table-cl-secundario } | Viabilidad baja { .table-bg-principal .table-cl-secundario } |
|---|---|---|---|
| **Alta** { .table-main-column .table-bg-principal .table-cl-secundario } | Actuar a corto plazo. | Planificar y preparar los recursos. | Planificar a largo plazo y buscar recursos o alianzas. |
| **Media** { .table-main-column .table-bg-principal .table-cl-secundario } | Aplicar cuando existan recursos disponibles. | Planificar a medio plazo. | Revisar posteriormente. |
| **Baja** { .table-main-column .table-bg-principal .table-cl-secundario } | Aplicar si apenas requiere esfuerzo. | Revisar posteriormente. | Descartar por ahora. |

La matriz no sustituye al criterio de las personas que deciden, pero evita dos errores frecuentes: dedicar el esfuerzo solo a las acciones fáciles aunque sean poco importantes, y abandonar las acciones importantes porque no pueden hacerse de inmediato.

Una empresa gestiona una plataforma de inscripción y retransmisión de eventos.

## 6.5. Seguimiento y revisión

El plan debe revisarse periódicamente para comprobar:

- Si las acciones se han realizado.
- Si los indicadores han mejorado.
- Si han aparecido nuevos riesgos.
- Si las medidas deben modificarse.
- Si los resultados pueden comunicarse de forma transparente.

Si una acción no alcanza el resultado esperado, no significa que deba abandonarse. Puede ser necesario cambiar el plazo, los recursos o la forma de aplicarla.

La comunicación de los resultados cierra el ciclo. Como se vio en la UP01, comunicar con transparencia implica mostrar tanto los avances como lo que queda pendiente, y explicar cómo se han medido. Así se evita que el plan se convierta en una herramienta de *greenwashing*.

## 6.6. Compromiso personal

El plan puede incorporar también una acción personal relacionada con la actividad profesional. Debe cumplir las características vistas en el apartado 5.3 y, como cualquier otra acción, incluir un plazo y una forma de comprobarla.

Por ejemplo:

> Durante los próximos seis meses, prolongaré el uso de mi equipo actual y priorizaré su reparación antes de considerar su sustitución. Lo comprobaré anotando cualquier avería y la decisión que tome sobre ella.

!!! bloque-descriptivo "Pregunta de reflexión final"
    ¿Qué acción relacionada con tu futura actividad profesional podrías comenzar a aplicar durante los próximos tres meses y cómo comprobarías su cumplimiento?
